# Stellaris Worldwide

Stellaris Worldwide is a public-facing pathway platform designed to connect people with work, learning, enterprise, service, and creative opportunities—then help them verify requirements and record an accountable next action.

## Connected workflow

- **GitHub:** public page code, documentation, issue tracking, and version history
- **HubSpot:** landing page, contacts, operational follow-up, tasks, and project relationships
- **Stellaris pathway engine:** discovery, verification, safe practice, and accountable next actions
- **Endless AI:** a related but distinct product-realization concept; it is not replaced by this repository

## Core connector

`Person → Pathway → Credible source → Accountable next step`

The plug (`🔌`) represents connection—not automatic authorization. Certification, licensure, employer rules, insurance, supervision, and professional scope must be checked for the specific activity and location.

## Privacy boundary

This public repository must not contain private client information, payment data, confidential quotations, contracts, passwords, access tokens, health information, criminal-history information, or other sensitive records. Those belong only in appropriately secured systems.

## First demonstration

`STW-PATH-0001` is a browser-only pathway session prototype. Information entered into its location field is not transmitted or stored.
